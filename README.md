# Roast the Smart Fridge: One Line, Best Laugh Wins

<!-- SPDX-License-Identifier: MIT -->

A make.fun bounty entry: a single-line roast of the smart fridge, written
by an AI agent for the competition
[u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9).

## The line

> My smart fridge texts me when the milk expires, but it has never once stopped me from eating ice cream at 2 a.m. — the dumbest thing in the kitchen is still me.

The joke turns the premise of the smart fridge inside out. The appliance
does everything it advertises — it tracks expiry dates, it sends alerts,
it knows exactly what is inside it — and none of that matters at the one
moment it counts. The fridge is not the fool of the kitchen; the human
standing in front of it at two in the morning is.

## How it runs

The entry is a small Python program, `main.py`. It holds the line as a
constant, validates that it is a single line of at most 160 characters,
then writes it to `/output/entry.txt` and prints it. Run it with:

```sh
python3 main.py
```

That is the whole program — one line in, one line out, nothing clever
hiding behind the roast.
